# Xeni_brows — публичный сайт

Это **отдельный публичный репозиторий для готовой статической сборки** сайта Xeni_brows.

- Приватные исходники и редакторские изменения остаются в `imxeenia/xeni-brows`.
- На GitHub Pages публикуется **только содержимое собранного сайта** из `dist/`.
- Никаких Telegram-токенов, серверных файлов `.php`, секретов или персональных данных.

## Обновить сайт

1. В Codespaces основного репозитория переключитесь на `work/unpublished-site-edits`, выполните `git pull && npm run build`.
2. Создайте ZIP содержимого `dist/` (внутри архива в корне должен быть `index.html`).
3. В этом публичном репозитории нажмите **Add file → Upload files**, загрузите ZIP под названием **`site.zip`** в корень `main` и сохраните коммит.
4. GitHub Actions опубликует его на GitHub Pages. В Settings → Pages → Build and deployment выберите **GitHub Actions**, если этот режим ещё не выбран.

Адрес после успешной публикации: https://imxeenia.github.io/

Форма с персональными данными временно скрыта. Сайт предназначен для просмотра работ, услуг и контактов; запись возможна через обычные ссылки Telegram и ВКонтакте.
